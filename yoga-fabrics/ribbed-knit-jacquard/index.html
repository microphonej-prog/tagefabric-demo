Buyer questions

Ribbed Knit & Jacquard — what buyers ask

What is the difference between rib and jacquard?

Rib is a stitch structure that produces vertical ridges — the elasticity runs across the ridges. Jacquard knits a pattern into the fabric by selecting needles, so the design is part of the structure rather than printed on it.

Does ribbed fabric stretch the same in both directions?

No. Rib is inherently more elastic across the ridges than along them. That matters for fit: ribbed panels need to be cut with the stretch direction in mind, and pattern engineering should account for it.

Can I get my own jacquard pattern?

Yes, subject to the machine and the minimum run. A design that fits an existing needle arrangement has a much lower minimum than a fully new pattern. Send us the artwork and we will confirm which route applies.

What is the minimum order?

300 kg per colour dyed-to-order for stock structures; new jacquard patterns carry a higher minimum set by the mill.
